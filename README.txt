LOBO LIMÓN — CÓDIGO FUENTE
==========================

Archivos incluidos:

- index.html: estructura y contenido de la página.
- styles.css: diseño completo y adaptación para móviles.
- script.js: enlaces de WhatsApp, preguntas frecuentes y año automático.
- assets/lemon-hero.webp: imagen principal.

CÓMO CAMBIAR EL NÚMERO DE WHATSAPP

Abra script.js y cambie:

const WHATSAPP_NUMBER = "50685427529";

Escriba el código de país y número sin espacios ni guiones.

No requiere instalación ni dependencias.
